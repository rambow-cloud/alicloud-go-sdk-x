# 已审核的文档译文

[English](README.md)

- 对应 #93。译文是可选的说明补充，不决定操作、字段或运行时能力的选择。
- 官方 Darabonba 发现流程仍自动执行，产品无需译文文件也能生成。
- 每个 `<product>.json` 绑定准确的来源清单，为已有中文操作摘要提供审核后的英文译文。
- 条目记录说明属性、原始来源坐标、parser 原文的 SHA256、英文译文和原始中文。
- 来源变化、未知操作、重复或不支持的属性、无效语言，或试图替换已有英文说明，均在生成写入前失败。
- 生成注释明确标注译文，保留 Apache 归属，并链接原始 DSL。
- 覆盖报告分别统计上游英文、审核译文和 Go 行为注释；字段缺少上游说明的情况继续显示。
- 译文不增加校验、分页、waiter 或重试策略，也不把账号、资源示例变成可执行测试。
