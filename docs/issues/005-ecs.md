# 提供首个 ECS 只读操作与端到端使用示例

### Affected areas

ecs

### 前置依赖

依赖 #3、#4；先固定官方 schema 和首个只读操作。

状态：GitHub issue #5（执行状态以 GitHub 为准）。

## 问题与证据

需用真实类型化产品 API 证明开发体验，而不是仅有框架接口。

来源：[上游证据](https://github.com/alibabacloud-go/ecs-20140526)。具体边界见 [调研](../research.md)。

## 范围

先固定 DescribeInstances 或同等只读操作的官方 schema、endpoint 和签名；依赖 transport/signing。

## 验收条件

- [ ] 补充固定版本 schema、字段可选性、官方操作文档链接
- [ ] ctx-first 类型 API，无 tea/dara 指针辅助依赖
- [ ] httptest 验证编码、签名集成、结果解码、服务错误、取消
- [ ] 解释 optional 与零值，给出可复制示例和迁移用法
- [ ] 只声明已实现操作，不宣称全量 ECS 支持

## 文档要求

每项公开 API 同时交付 doc.go、导出符号/字段注释和可执行外部 Example。
更新 README 支持范围与相关设计/发布说明。文档完成与代码完成属于同一交付。

## 验证计划

按验收条件建立离线行为测试，运行文档检查、vet 和相关测试一次。
涉及并发时由 Linux CI 运行 race；上线或 pkg.go.dev 页面由浏览器确认。
