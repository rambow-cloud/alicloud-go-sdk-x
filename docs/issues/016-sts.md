# [Feature]: Add a typed STS AssumeRole client and credential provider helper

## English

### Affected areas

sts, credentials

### Dependencies

#3, #9

### Problem and scope

Complete the shared runtime foundation before product generation. This issue delivers the capability described below; no full service coverage or live-cloud validation is claimed.

### Acceptance criteria

- [ ] Implement the documented STS AssumeRole RPC operation using the common runtime.
- [ ] Keep source credentials separate from assumed-role credentials and avoid dependency cycles.
- [ ] Map STS expiration into credentials and compose the helper with the shared cache.
- [ ] Test encoding, errors, session inputs, refresh and concurrency with fake STS responses.

### Documentation and verification

English-primary Go comments, external executable Examples, equivalent English/Chinese guides, offline behavior tests and relevant CI checks.
