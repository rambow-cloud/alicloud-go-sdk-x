## 执行前确定的范围

- 对应 #74；STS 前置项 #60 已完成，历史真实调用证据 #47 单独评审合入。
- 保持固定官方 Darabonba、官方语义解析器、完整 IR、公共生成后端和运行时；本次不计划更新来源或策略。
- 清单包含 380 个已发现操作，其中 283 个 RPC 操作可降低并生成，涉及 1,453 个模型。不支持的操作继续说明原因；能编译不代表所有操作都经过行为验证。
- 消费者使用独立模块 examples/productacceptance，只导入公共包，使用 Go 1.27、JSON v2、合成夹具，不访问网络。
- 验收者是实现代理。不记录人工任务耗时，不宣称性能优势、整体 Beta 或源码兼容。

## 必需验收项

| 验收项       | 必需证据                                                                                              |
| ------------ | ----------------------------------------------------------------------------------------------------- |
| generation   | 官方前端检查与测试、兼容桥及产品确定性检查、生成包编译；选中不支持行为时写入前失败                    |
| consumer     | DescribeRegions、镜像遍历、实例 token/页码遍历、小型 mock、原生 Profile 和生成 STS 配合缓存           |
| pagination   | 空页、短页、完整页、总数、重复 token、互斥模式、所有权、可选字段、错误响应及失败/取消后的游标稳定     |
| waiter       | Wait 和 WaitForOutput、全部目标 ID、缺失/部分/重复/未知观察、状态变化、错误、截止时间及并发复用       |
| retry-errors | 已审核读取重试、写入不重试、选项与 endpoint、结构化错误和 Metadata、取消及不泄露敏感信息的注入式 OTel |
| live         | 复用 #47 的 SDK/CLI 选定字段比较及镜像真实翻页；确认受测契约未改变                                    |
| docs         | 可运行消费者和 Example、中英文指南、文档检查、来源和许可证说明、明确范围限制                          |

- 必需真实调用项复用 2026-10-08 已通过的只读结果：DescribeRegions、DescribeImages 两页遍历、DescribeInstances token/页码模式终止页、DescribeInstanceStatus 终止页。
- 本次 v0.1.0 范围内，真实实例 token 续页及 waiter 状态迁移属于可选、排除项：授权账号样本没有实例。继续记录 NOT RUN/SKIP，不改为 PASS。
- token 续页和 waiter 状态变化、错误契约仍是必需离线项；不为补充真实覆盖创建或修改实例。
- 本范围不代表满足 product-acceptance.md 中整体 Beta 对真实 token/waiter 迁移的要求；Explorer 网页验证仍为 NOT RUN。
- 复用未改变的 STS、Profile 和来源升级证据；发布及同版本 pkg.go.dev 索引由 #61 完成。
