## 执行前确定的范围

- 对应 #75；#60 和历史真实调用证据合入项 #47 已完成，ECS #74 单独评审。
- 保持固定官方 Darabonba、官方语义解析器、完整 IR、公共生成后端和运行时；不更新来源或策略，不凭空添加 token 或 waiter。
- 已发现 403 个操作，其中 296 个可降低并生成，涉及 1,242 个模型；其余 107 个继续记录不支持原因。
- 扩展独立消费者 examples/productacceptance，通过公共包、合成响应、小型 DescribeVpcsAPI mock 和应用持有的 OTel 验证，不需要网络或云账号。
- 验收者是实现代理，不宣称独立人工耗时、性能、全云覆盖或整体 Beta。

## 必需验收项

| 验收项       | 必需证据                                                                                                             |
| ------------ | -------------------------------------------------------------------------------------------------------------------- |
| generation   | 复用未改变的官方前端及 57 项测试、确定性生成器检查，编译完整支持清单；选中不支持行为时写入前失败                     |

| pagination   | 多页、空页、短页、总数与边界、失败和取消后的稳定状态、模型和选项所有权、准确页码字段及嵌套可选模型                   |
| retry-errors | 显式启用的审核读取重试、写入保守处理、签名 endpoint/调用覆盖、Metadata 和错误、调用中截止时间及 tracing 敏感信息保护 |
| live         | 复用 #47 已通过的 DescribeVpcs 空终止页选定字段比较；受测契约、运行时和策略未改变                                    |
| docs         | 配对指南与报告、可运行消费者和 Example、来源和许可证、文档检查及明确限制                                             |

- 必需真实调用项：2026-10-08 已接受的 DescribeVpcs SDK/CLI 读取，以及原生终止页元数据、所有权和取消检查。

- DescribeVpcs 遍历不需要 waiter，不根据 Status 字段推断或添加等待器。
- 后来生成的无请求模型操作 ListGeographicSubRegions 不属于 #47 真实覆盖；补充独立离线用例，不扩大历史真实调用结果。
- 整体 Beta 的真实续页要求和 Explorer 网页证据仍单独跟踪；本次不执行新云调用、资源写入、来源更新或发布。
- [后续项 #79](https://github.com/rambow-cloud/alicloud-go-sdk-x/issues/79)在有合适且获授权的现有资源时验证真实实例 token、waiter 状态迁移及非空 VPC 续页，不属于本次 v0.1.0 门禁。

## 验证与结果

- 只有来源和运行时未改变时，才复用 ECS 阶段已通过的前端、生成器和根模块检查。执行新增 VPC 独立测试、vet/运行、格式和语言检查，以及最终提交的 Linux race、Windows 和自动化 CI。
- 在最终共用消费者及 CI 版本上更新 STS、ECS 机器证据；任务改变后不能靠旧版本绕过发布检查。
- 在 acceptance/vpc-product-result.json 记录实际测试事件、版本、提交、覆盖和限制。
- PASS：提交 85795cf3cf1604afe59b0e8af03d5df0c9d3ba38 上的八项外部消费者测试、十个子用例全部通过；实际版本和耗时见[机器记录](acceptance/vpc-product-result.json)。
- PASS：原生遍历、mock 业务结果、边界与失败状态稳定、字段与选项、读取重试和写入保守处理、Profile 与共用 STS 缓存、OTel、无请求模型用例及取消/截止时间。
- PASS：消费者 vet/运行、格式、语言和本地链接；未改变的前端、生成及根模块证据复用 #74 的结果。
- STS（11 项）、ECS（10 项、14 个子用例）、VPC（八项、十个子用例）在同一干净任务版本上重新执行通过。必需真实调用证据仍按预先确定的范围保留历史记录。
- 最终提交合并前必须通过 Linux race、Windows、自动化和 issue 关联检查；准确 CI/合并链接记录在 #75 及 PR。
- 本结果仅完成明确范围内的代理产品验收。#79 的真实调用缺口、可选人工体验和 #61 发布/索引继续单独跟踪。
