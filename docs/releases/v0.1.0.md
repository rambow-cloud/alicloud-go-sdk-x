# v0.1.0 — generated STS, ECS and VPC

[中文](v0.1.0.zh-CN.md)

- Experimental release of an independent Alibaba Cloud Go SDK. APIs may change before v1.
- Requires Go 1.27+. Uses `encoding/json/v2` directly; no experiment flag or Tea runtime.
- Install after publication: `go get github.com/rambow-cloud/alicloud-go-sdk-x@v0.1.0`.
- Publication and same-version pkg.go.dev indexing are recorded in [the release checklist](../sts-v010-release-checklist.md).

## Generated services

- Official Darabonba sources → official semantic parser → complete normalized IR → our Go backend → shared runtime.
- `service/sts`: all 4 pinned actions, including AssumeRole, GetCallerIdentity, AssumeRoleWithOIDC and AssumeRoleWithSAML.
- `service/ecs`: 380 actions. `service/vpc`: 403 actions. Generation and compilation counts do not imply all-action live acceptance.
- AWS Go SDK v2 conventions for Options, NewFromConfig, operation options, paginators and reusable waiters. No AWS or official Alibaba source compatibility is claimed.
- Native wire fields, meaningful absence and response containers. Metadata, small mock interfaces and deterministic offline Examples.
- Reviewed adapters: ECS 12/VPC 13 paginators and ECS 2/VPC 3 waiters. Unlisted capabilities remain unreviewed; page-only APIs do not acquire NextToken.
- ROA escaped resource paths are supported in the shared runtime. Generated ROA bodies, XML and streaming remain #92 work.

## Credentials and request behavior

- Prefer temporary STS credentials. Config/Options take providers, never bare AK/SK. Long-lived credentials require explicit providers or loader opt-in.
- LoadDefaultConfig discovers temporary environment, OIDC, URI and native CLI Profile sources. Native profiles include OAuth, URI, process, ECS role, OIDC and CloudSSO; [precedence and limits](../default-configuration.md) apply.
- Native OAuth performs bounded refresh and atomic session persistence. CloudSSO interactive login remains separate.
- Renewable OIDC/SAML providers reload token sources and reuse generated STS and shared caching. Register SAML providers explicitly.
- Anonymous OIDC/SAML calls never retrieve source keys or sign. Signed actions reject the anonymous marker.
- HTTPS, no authentication redirects, no retry by default, 30-second total deadline and 8 MiB response limit.
- Opt-in retry is bounded and requires reviewed safety; token issuance and arbitrary writes do not retry by default.
- Inputs and options are copied. Clients support concurrent calls; shared extensions must follow their concurrency contracts.
- Official endpoint maps/rules and reviewed private combinations; explicit BaseEndpoint wins. Constructed endpoints do not prove connectivity.
- Use errors.As for service errors and errors.Is for cancellation/deadlines. Unknown JSON fields are tolerated; duplicate names and invalid UTF-8 are rejected.
- Default errors, traces and sensitive model formatting redact secrets. Direct fields/explicit JSON still contain raw values. Optional OpenTelemetry sets no global exporter/provider.
- Core runtime uses only the standard library. Official comparison dependencies live in isolated modules.

## Evidence and limits

- [Fresh agent consumer evidence](../release-consumer-refresh.md) covers STS/ECS/VPC at the actual integrated SDK pin. Independent human UX #76 remains optional/NOT RUN; test time is not human task time.
- [Real STS renewal](../live-sts-renewal.md): 900-second AssumeRole expiration/renewal and cleanup passed.
- [Native OAuth refresh](../native-oauth-renewal.md): one real refresh grant and STS exchange, actual refresh-token replacement, identity reads, cache, persistence and reconstruction passed. Triggered by invalidating cached expiry metadata using the real clock; natural OAuth expiry was NOT RUN.
- [Existing-resource reads](../live-resource-followup.md): nonempty VPC fields and current Available-state waiters passed in Beijing/Zhangjiakou. No ECS instances were found; same-region multi-page and lifecycle transitions remain NOT RUN.
- Live OIDC/SAML federation remains NOT RUN, outside the declared required release scope. Offline contracts do not prove an IdP/trust deployment works.
- Explorer browser evidence is separate from CLI/SDK evidence. [Pinned runtime comparison](../runtime-comparison.md) measures one STS fixture, not universal performance.
- [Documentation translations](../documentation-gap-completion.md) fill nine Chinese-only ECS summaries. Missing upstream field business prose remains separately reported from Go contracts.
- Final-main Linux race/Windows and release guards precede publication. This is scoped experimental acceptance, not broader Beta or whole-cloud acceptance.
