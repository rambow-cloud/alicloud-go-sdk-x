# v0.1.0 — generated STS / 生成的 STS

## English

This scoped experimental release targets STS 2015-04-01 through pinned official
Darabonba -> official parser -> complete normalized IR -> our Go backend -> shared
runtime. It is an independent SDK, not an official Alibaba Cloud SDK. APIs may change
before v1. Publication/indexing evidence is recorded separately in the
[release checklist](../sts-v010-release-checklist.md); this document alone is not a tag.

### Scope and behavior

`service/sts` includes all four actions in the pinned source: AssumeRole,
GetCallerIdentity, AssumeRoleWithOIDC and AssumeRoleWithSAML; 19 reachable named/
inline models, operation-specific interfaces and deterministic offline Examples.
The empty GetCallerIdentityInput supplies the uniform context/Input/options call
shape without inventing request fields. Native field names, absence and response
containers are preserved; no artificial STS paginator or waiter is added.

Service Options, NewFromConfig, operation functional options, small mock seams and
shared paginator/waiter conventions follow AWS Go SDK v2 style. This is a calling
convention, not AWS or official Alibaba source compatibility. Native optional fields
use pointers and int64 where modeled. Outputs add Metadata; inspect service errors
with errors.As and cancellation/deadlines with errors.Is. Unknown JSON response
members are tolerated; duplicate names and invalid UTF-8 are rejected.

Config/Options accept explicit providers, never bare keys. Prefer generated STS ->
AssumeRoleProvider -> Cache -> consumer. StaticProvider/EnvProvider are deliberate
secondary choices; custom providers remain supported. Nil/typed-nil providers fail
before transport. AnonymousProvider explicitly configures OIDC/SAML use; these
operations never retrieve source keys or sign. Signed actions reject the marker.
Supply federation tokens/assertions explicitly; there is no implicit Profile/OAuth,
environment discovery or federation provider helper.

Defaults: HTTPS, no authenticated redirects, no retries, 30-second total request
deadline, 8-MiB response limit. Reviewed opt-in retries remain bounded and idempotency
aware; token issuance stays non-retryable. Inputs/configuration are copied and clients
are concurrency safe. Custom providers/transports/hooks must honor their documented
contracts. Default errors, tracing and sensitive-model String/GoString omit secrets;
direct fields and explicit JSON are raw and must not be logged. Optional OTel does
not configure global exporters/providers. Runtime core imports only the standard
library; official comparison dependencies live in their own consumer module.

### Evidence and limitations

All four actions have separate discovered/lowered/emitted/compiled/offline evidence.
Live scope is cn-hangzhou: #55 accepted actual 900-second AssumeRole expiry renewal
and cleanup; #60 generated identity matched six CLI fields/presence using an explicit
in-memory OAuth/STS snapshot. This is not native SDK Profile/OAuth renewal.
**Successful OIDC/SAML live federation: NOT RUN, outside predeclared required live
scope.** Their complete offline contracts do not establish working IdP/trust/assertion
deployments. Explorer browser evidence is separate from CLI/SDK evidence.

Real source-revision maintenance rehearsal, isolated official STS v2.1.0 comparison
and independent docs-only developer evidence are tracked in [the acceptance report](../sts-v010-acceptance-report.md).
Required independent acceptance and final-commit Linux race/Windows CI precede
publication. Other available `service/ecs`, `service/vpc`, shared engines and the
`services/` bridge retain their separately recorded acceptance; this release does
not claim broader ECS/VPC/STS Beta or whole-cloud coverage. Benchmarks remain separate.

### Migration and licensing

Use `github.com/rambow-cloud/alicloud-go-sdk-x/service/sts`; retain `services/sts`
only for the bounded reference bridge. Adapt optional pointers, native complete
response containers and the full-DSL provider constructor; do not silently alias
bridge response shapes. There is no Tea runtime requirement for generated clients.
The canonical module requires Go 1.27+ and imports encoding/json/v2 directly,
without an experiment flag. After the immutable tag is published, install with
`go get github.com/rambow-cloud/alicloud-go-sdk-x@v0.1.0`.

### 范围与行为

`service/sts` 覆盖固定来源四操作 AssumeRole/GetCallerIdentity/AssumeRoleWithOIDC/
AssumeRoleWithSAML、19 个可达命名/内联模型、小接口及确定性离线 Example。空
GetCallerIdentityInput 保持 context/Input/options 调用，不造请求字段；保留原生字段、
缺失/响应容器，不为 STS 添加虚构分页或 waiter。

Options/NewFromConfig/操作 functional options/小 mock 接口/共享分页-waiter 范式借鉴
AWS Go SDK v2，但不宣称与 AWS 或官方阿里云源码兼容。按模型使用可选指针和 int64，
输出增加 Metadata；errors.As 取服务错误、errors.Is 识别取消/超时。JSON 容忍未知
响应字段、拒绝重复名称/非法 UTF-8。

Config/Options 只接显式 provider，不接裸密钥。推荐生成 STS → AssumeRoleProvider →
Cache → 消费者；StaticProvider/EnvProvider 是二等显式选择，自定义 provider 保留。
nil/typed-nil 请求前失败。显式 AnonymousProvider 配置 OIDC/SAML，两操作不读来源密钥/
不签名，签名操作拒绝标记。token/assertion 显式传入，不隐式发现 Profile/OAuth/环境，
不提供联邦 provider helper。

默认 HTTPS、禁止认证重定向、不重试、总期限 30 秒、响应上限 8 MiB。经审核显式重试
有界并依幂等性决定，token 签发不重试。复制输入/配置、client 可并发，自定义 provider/
transport/hooks 遵循契约。默认错误、trace、敏感模型 String/GoString 隐藏秘密；直接
字段/显式 JSON 原样，不能记录。可选 OTel 不设全局 exporter/provider。核心 runtime
仅导入标准库，官方对比依赖在独立消费者模块。

真实来源维护、固定官方 v2.1.0 对比及独立文档开发者证据见[验收报告](../sts-v010-acceptance-report.md)。
