# v0.1.0 — 生成的 STS、ECS、VPC

[English](v0.1.0.md)

- 独立阿里云 Go SDK 的实验版本，v1 前 API 可能变化。
- 要求 Go 1.27 及以上，直接使用 `encoding/json/v2`，无需实验开关或 Tea 运行时。
- 发布后安装：`go get github.com/rambow-cloud/alicloud-go-sdk-x@v0.1.0`。
- 发布与相同版本 pkg.go.dev 索引证据记在[发布清单](../sts-v010-release-checklist.zh-CN.md)。

## 生成的服务

- 官方 Darabonba 源码 → 官方语义 parser → 完整规范化 IR → 本项目 Go 后端 → 公共运行时。
- `service/sts` 覆盖固定来源的全部 4 个操作：AssumeRole、GetCallerIdentity、AssumeRoleWithOIDC、AssumeRoleWithSAML。
- `service/ecs` 有 380 个操作，`service/vpc` 有 403 个操作。生成和编译数量不代表全部操作已通过真实云验收。
- Options、NewFromConfig、操作选项、分页器及可复用 waiter 借鉴 AWS Go SDK v2 范式，不宣称与 AWS 或官方阿里云 SDK 源码兼容。
- 保留原生线字段、有意义的缺失状态和响应容器；提供 Metadata、小型 mock 接口及确定性的离线 Example。
- 已审核适配器：ECS 12/VPC 13 个分页器，ECS 2/VPC 3 个 waiter。未列能力仍未审核，不为纯页码 API 增加 NextToken。
- 公共运行时支持 ROA 转义资源路径；ROA 正文生成、XML 和流式处理继续由 #92 跟踪。

## 凭据与请求行为

- 优先使用临时 STS 凭据。Config/Options 接受 provider，不接裸 AK/SK；长期凭据须显式声明 provider 或启用加载选项。
- LoadDefaultConfig 发现临时环境凭据、OIDC、URI 和原生 CLI Profile。原生模式包括 OAuth、URI、外部进程、ECS 角色、OIDC、CloudSSO；遵循[优先级和限制](../default-configuration.zh-CN.md)。
- 原生 OAuth 提供有超时上限的刷新和原子会话持久化；CloudSSO 交互登录单独完成。
- 可续期 OIDC/SAML provider 重新读取 token 来源，复用生成 STS 和公共缓存；SAML provider 需显式注册。
- 匿名 OIDC/SAML 调用不读取来源密钥、不签名；签名操作拒绝匿名标记。
- 默认 HTTPS、不跟随认证重定向、不重试，总期限 30 秒、响应上限 8 MiB。
- 显式重试受次数、时间及已审核安全策略约束；token 签发和任意写操作默认不重试。
- 复制输入与选项，客户端可并发调用；共享扩展遵循各自的并发契约。
- 官方端点表、规则及已审核私网组合，显式 BaseEndpoint 优先；能构造端点不代表真实网络可达。
- errors.As 提取服务错误，errors.Is 识别取消或期限到达。JSON 容忍未知字段，拒绝重复名称和非法 UTF-8。
- 默认错误、trace、敏感模型格式化隐藏秘密；直接字段和显式 JSON 仍含原始值。可选 OpenTelemetry 不设置全局 exporter/provider。
- 核心运行时仅使用标准库，官方对比依赖位于独立模块。

## 证据与限制

- [本轮代理消费者证据](../release-consumer-refresh.zh-CN.md)以实际集成版本验证 STS、ECS、VPC。独立人工体验 #76 可选且未执行，测试耗时不代表人工任务耗时。
- [真实 STS 续期](../live-sts-renewal.zh-CN.md)：900 秒 AssumeRole 自然到期、续期及清理通过。
- [原生 OAuth 刷新](../native-oauth-renewal.zh-CN.md)：真实 refresh grant、STS 交换、服务端 refresh token 替换、身份读取、缓存、持久化及重建通过。使用真实时钟使缓存到期标记失效来触发；未验证 OAuth 自然到期。
- [现有资源读取](../live-resource-followup.zh-CN.md)：北京、张家口的 VPC 非空字段和当前 Available 状态 waiter 通过。未找到 ECS 实例，同地域真实跨页及生命周期转换仍未执行。
- OIDC/SAML 真实联邦仍未执行，预先排除在本版本必需真实验收范围之外；离线契约不证明 IdP 或信任配置已经部署成功。
- Explorer 浏览器证据与 CLI/SDK 证据分开；[固定版本的运行时对比](../runtime-comparison.zh-CN.md)只测量一个 STS 夹具，不代表普遍性能。
- [文档译文](../documentation-gap-completion.zh-CN.md)补齐 9 个只有中文摘要的 ECS 操作；缺失的上游字段业务说明与 Go 行为注释分开报告。
- 发布前要求最终 main 的 Linux race、Windows 和发布检查通过。本次是限定范围的实验验收，不是广泛 Beta 或全云验收。
