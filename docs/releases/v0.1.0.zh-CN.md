### 范围与行为

- `service/sts` 覆盖固定来源四操作 AssumeRole/GetCallerIdentity/AssumeRoleWithOIDC/ AssumeRoleWithSAML、19 个可达命名/内联模型、小型接口及确定性离线 Example。
- 空 GetCallerIdentityInput 保持 context/Input/options 调用，不造请求字段；保留原生字段、 缺失/响应容器，不为 STS 添加虚构分页或状态等待器。

- Options/NewFromConfig/操作函数式选项/小测试替身接口/共享分页-状态等待器范式借鉴 AWS Go SDK v2，但不表示与 AWS 或官方阿里云源码兼容。
- 按模型使用可选指针和 int64， 输出增加 Metadata；errors.As 取服务错误、errors.Is 识别取消/超时。
- JSON 容忍未知响应字段、拒绝重复名称/非法 UTF-8。

- Config/Options 只接显式凭据提供者，不接裸密钥。
- 推荐生成 STS → AssumeRoleProvider → Cache → 消费者；StaticProvider/EnvProvider 是二等显式选择，自定义凭据提供者保留。
- nil/带类型的 nil 请求前失败。
- 显式 AnonymousProvider 配置 OIDC/SAML，两操作不读来源密钥/ 不签名，签名操作拒绝标记。
- 令牌或身份断言显式传入，联邦辅助组件仍为单独范围；用户要求 #68 默认加载/原生 CLI Profile/OAuth、有刷新超时的续期及原子持久化，发现临时环境来源，长期密钥仍显式启用。
- 模式及优先级按[契约](../default-configuration.zh-CN.md)， 不提供联邦凭据提供者辅助组件。

- 默认 HTTPS、禁止认证重定向、不重试、总期限 30 秒、响应上限 8 MiB。
- 经审核显式重试受次数与时间限制，并由幂等性决定，token 签发不重试。
- 复制输入/配置、client 可并发，自定义凭据提供者/ HTTP 传输实现/hooks 遵循契约。
- 默认错误、trace、敏感模型 String/GoString 隐藏秘密；直接字段/显式 JSON 原样，不能记录。
- 可选 OTel 不设全局导出器或 TracerProvider。
- 核心运行时仅导入标准库，官方对比依赖在独立消费者模块。

### 证据与限制

- 四操作分开记录发现/转换为 IR/生成代码/编译/离线证据。
- 真实范围 cn-hangzhou：#55 已验收真实 900 秒 AssumeRole 到期续期与清理；#60 用显式内存 OAuth/STS 快照，生成 identity 的六字段/缺失状态与 CLI 一致，不是原生 SDK Profile/OAuth 续期。
- #68 独立验证原生 Profile 加载、生成身份读取、主动 OAuth 交换、缓存及持久会话重建通过，见[原生证据](../acceptance/profile-oauth-live.json)；真实 refresh-token 轮换及等待 OAuth 自然到期仍 NOT RUN，与离线轮换测试数据分开。
- **OIDC/SAML 真实成功联邦 NOT RUN，预先位于必需真实范围外**；完整离线契约不证明 IdP/trust/身份断言 部署成功。
- Explorer 浏览器与 CLI/SDK 证据分开。

- 真实来源维护、固定官方 v2.1.0 对比及独立文档开发者证据见[验收报告](../sts-v010-acceptance-report.zh-CN.md)。
- 发布前必须完成独立验收及最终提交 Linux race/Windows CI。
- 已有 ECS/VPC/共享引擎及 `services/` 桥保留各自证据，不表示更广 Beta、全云覆盖或基准结果。

### 迁移与许可

- 使用规范导入 `github.com/rambow-cloud/alicloud-go-sdk-x/service/sts`，`services/sts` 仅保留覆盖少量操作的兼容参考实现；迁移需适配可选指针、完整原生容器及完整 DSL 凭据提供者构造器， 不静默 alias 桥响应。
- 生成 client 不需 Tea 运行时。
- module 最低 Go 1.27、直接 JSON v2， 无实验开关；不可变标签发布后才使用上述 `go get ...@v0.1.0` 安装。

- 生产官方来源修订/语义解析器/manifest SHA256 与英文列值相同，演练不更新生产 pin。
- 原创运行时/工具为 MIT，生成定义/说明保留 Apache-2.0、服务 LICENSE/NOTICE、准确来源/ 许可字节。
- API 同步英文 pkg.go.dev 注释/Examples 和配对中文使用/契约/来源指南；明确报告上游语言/说明缺失。
- 禁止覆盖版本标签。
