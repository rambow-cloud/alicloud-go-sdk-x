- 仅接受一个 UTF-8 文档，限制字节、深度和元素数量，并检查 context。拒绝指令、不支持的处理指令和模型中的混合内容。错误文本不包含原文，解码失败不发布部分结果。
- 根据审核过的根元素和具体模型，生成确定且正确转义的 XML。不支持的类型、循环模型或超限输出在返回字节前报错。测试不使用账号、网络或凭据，不调用云 API 或创建资源。
- 验收包括独立的合成请求/响应用例、确定输出的外部 Example、根模块 Go 文档检查/vet/测试、格式、配对文档以及最终提交的 Linux race/Windows CI。
- 本阶段不增加公共操作、OSS 签名或 XML 生成器。生产 OSS 接入仍须把固定来源/helper 的线协议特征纳入 IR，处理端点和子资源、OSS 签名以及流与校验和契约；不能宣称已生成 OSS 或完成整个 #92。

## 内部契约

- `internal/xmlmodel.Root` 提供准确的 `xml.Name`；`ScalarField` 指定承接根文本的字段。它不是 SDK 公共 API，也不是永久的逐操作配置表。
- `Decode(ctx, bytes, root, &model)` 完全成功后才发布全新输出；`Encode(ctx, root, model)` 返回独立持有的字节，失败时不返回部分字节。
- 字段使用原生 `json` 线名称。支持字符串、布尔值、有符号整数、有限浮点数、可选标量/结构指针，以及重复的标量/结构元素。不支持 map、字节、嵌入或递归模型、重复名称及指向 slice 的指针。
- 限制为 8 MiB、64 层元素、65,536 个元素。命名空间须使用绝对 URI；允许 UTF-8 BOM 和 XML 1.0 声明。命名空间属性须有效，其他属性不写入模型字段。
- nil 可选字段省略；显式空标量保留。空数组不生成元素，数组中的 nil 项报错。未知响应子元素允许忽略，但整个文档仍须符合语法和大小限制。
- `ErrInvalid`/`ErrLimit` 不包含响应原文或字段值；取消错误可用 `errors.Is` 识别。编解码器没有共享可变状态，调用者使用期间须独占模型和输出。
- 使用 `go test ./internal/xmlmodel` 运行独立夹具及外部 Example。
