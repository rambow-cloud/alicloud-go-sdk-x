# RPC DSL 支持扩展

[English](dsl-rpc-expansion.md)

## 问题与范围

- 固定的 ECS DSL 包含 380 个操作，在 #83 之前生成 283 个。
- 首个阻塞原因分为三类：80 个重复 query 绑定、7 个输入字段弃用属性、10 个 shrink 请求签名。
- 扩展共用的官方 parser → IR → Go 流程，不手写操作客户端，不修改上游源码。
- 相同规则应用于所有固定产品；能力策略仍需单独审核，重试保持显式启用。

## 实现顺序

- 相同条件下，把同一输入字段重复赋给同一 query 键的语句合并。来源、条件、别名或转换不同的绑定仍拒绝。
- 支持布尔类型的 `deprecated` 字段属性，保留字段，并生成带来源说明的英文 `Deprecated:` 注释。
- 识别官方的临时请求、shrink 模型校验及转换流程。
- IR 明确记录 JSON 字符串参数转换，包括原始输入字段、准确线路径和编码方式。
- 产品 IR 及其锁文件升级为 schema v2，不匹配的版本在写文件前拒绝；覆盖报告仍使用独立的 v1 schema。
- 公开输入保留结构化类型；转换字段编码为单个 JSON query 值，普通数组仍采用从 1 开始的参数索引。
- 保留 nil 与显式空值的区别、取消行为、输入副本及中间件契约。

## 验收与验证

- parser 测试覆盖固定 ECS 的真实模式，拒绝篡改后的转换、编码风格、绑定和属性。
- IR 和 Go 后端在写文件前拒绝未知编码，不按操作名添加特例。
- 离线签名请求测试检查重复键归一化、弃用字段、JSON 参数、缺失与空值、输入所有权及取消。
- 增加可执行示例及配对的生成指南；Go 检查前先运行 Node 22 前端检查和测试。
- 重新生成 IR 和 Go；实现后各执行一次 product-check、doccheck、vet、Go 测试和格式检查。CI 覆盖 Linux race 和 Windows。
- 重新统计所有产品，记录后续阻塞原因。生成和编译数量不代表真实云调用已验收。
- 本次不执行真实写操作、不打发布标签、不发布 pkg.go.dev。保留历史验收及真实调用提交；受影响的离线消费者记录更新到同一任务提交。

## 结果

- Issue：[#83](https://github.com/rambow-cloud/alicloud-go-sdk-x/issues/83)。
- ECS：发现、降低及生成均为 380 个，包含 2,053 个模型，没有剩余降低阻塞。
- VPC：发现 403 个，降低及生成 396 个，包含 1,671 个模型。剩余 7 个：4 个未完整绑定的输入流程、1 个不同的 query 初始化流程、2 个非 JSON shrink 流程。
- STS 不变：4 个操作、19 个模型。
- Node 22 前端检查及 73 项测试、product-check、文档检查（15 个包）、vet、根模块测试及 Example 均通过。上游来源、少量能力策略及 STS Go 产物未变。
- 消费者共同任务提交：`01f25a9a571c3b59024dfbef7e2e96f7605f4a55`。
- 两个独立模块的 vet 和离线程序通过。STS：11 项原有用例及 1 项固定官方 JSON helper 对比；ECS：10 项及 14 个子用例；VPC：8 项及 10 个子用例。更新后的记录固定到同一提交，历史真实调用证据保留。
- 评审修复：JSON 编码建立一次索引，IR 强制使用 schema v2。旧锁文件和混合版本 IR 均在写文件前拒绝。JSON 字段的类型化 nil 遵循上游 isUnset 条件，嵌套 null 及空值保留。
- 修复后，Node 检查及 73 项测试、product-check、文档检查、vet、根模块测试及 Example 均通过。生成的 Go 代码及指南字节未变。
- 受版本控制 Go 文件的格式检查通过。合并前要求最终提交的 CI 通过；最新结果见 [PR #84 检查](https://github.com/rambow-cloud/alicloud-go-sdk-x/pull/84/checks)。
- CI 后续修复：[运行 37913736842](https://github.com/rambow-cloud/alicloud-go-sdk-x/actions/runs/37913736842) 在隔离编译测试运行期间，触发 Go 默认的 10 分钟包级期限。此前 race 测试套件曾用 335 秒通过。针对扩展后的生成范围，CI 显式设置 20 分钟包级期限，保留 race 检查、全部测试和编译子进程独立的 180 秒期限。
- 数量表示固定来源的生成范围，不表示 ECS/VPC 全部经过真实调用验收。
