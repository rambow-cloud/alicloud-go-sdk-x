# FC ROA 产品生成

[English](fc-roa-product.md)

- 对应 #92，依赖 PR #109 的显式响应模式运行时能力。
- 使用 `ec489e5c3deae95496daae2b41503ac58b221adb` 中完整的官方 `fc-20230330` DSL、原始 Teafile/目录以及已固定的导入模块。保留全部上游字节和许可声明。
- 官方 parser 调研发现 73 个 WithOptions 操作：54 个 JSON 响应、18 个 none 和 1 个二进制响应。发现阶段保留全部操作，生成阶段明确列出不支持的原因。
- 识别准确的路径插值、请求头 map、带条件的 query 字段、整个模型或 body 字段的 JSON 转换及 callApi 调用。不接受任意 DSL 语句，也不根据名称猜测参数映射。
- 按真实路径参数、请求模型字段和请求头生成操作输入，保留来源坐标和准确线字段。共享正文模型需要独立的操作输出外观类型，同时保留公共模型定义。
- 空正文输出仍包含操作元数据；只有来源明确声明 none，才使用运行时的相应模式。二进制输出在流所有权和重放规则完成前保持不支持。
- Go 字段注释说明实际路径、query、请求头和正文位置。Body 不增加 JSON 包装字段，Headers 不表示名为 headers 的单个请求头；JSON 输出与仅含元数据的 none 输出分别说明。
- 固定来源中 `ap-southeast-5` 的端点末尾包含制表符。记录准确源码哈希、原值及已审核的去除尾部空白决策；不改上游源码，未批准的漂移在写入前失败。
- 本阶段仅做离线验证；该计划不授权创建 FC 资源或执行真实写操作。

## 验证

- 完整来源发现及确定性的 parser/IR/生成器检查。选中二进制操作或未知转换时，写入前失败。
- 生成代码的独立线路测试覆盖多个路径参数的转义、JSON 正文形状、请求头、query 的缺失和零值、JSON/none/错误响应以及输入所有权。
- 必填字段的 Example 使用虚构值和离线传输器。包、符号及配对产品文档由生成器输出，并保留来源和许可信息。
- 先执行 Node 22 前端测试/检查，再执行 Go 文档、vet、测试和生成检查；合并前要求当前提交的 Linux race 与 Windows CI 通过。
- 发现、降低、输出、编译及真实行为的覆盖分别记录。XML、二进制流和其他签名协议仍作为 #92 后续项。

## 已交付的离线范围

- IR/锁文件使用 schema v5、profile openapi-json-v1。发现 73 个操作，降低、生成并编译 72 个，输出 331 个模型及 72 个可执行 Example。InvokeFunction 以 DSL_RESPONSE_BODY_PROFILE 明确排除，不宣称支持二进制流。
- 来源清单 SHA256：fda7bc19fbbeb45b230c5dc9c4e69452a1dfe57331452f62dc653261b6d13254。原 STS/ECS/VPC 的策略和翻译重新绑定扩展后的来源集合，审核内容未变；原产品生成的可执行 Go 代码未变。
- 复用测试对 ROA 产品和操作改名。未知语句、条件、转换、query 编码、路径映射、XML 模式及不支持的选择在输出前失败；无效端点决策在写入 IR 前失败。
- 字段业务说明：1591 个字段中，1118 个有来源英文说明；全部 1591 个都有生成的 Go 契约注释。本阶段未增加 FC canonical 说明集合或已审核的中文业务翻译。配对指南覆盖用法、行为及来源，缺失业务说明仍归 #93。
- Node 22 共覆盖 98 项测试：首轮通过 90 项，修正夹具后相关 29 项全部通过；前端一致性检查通过。Go 全量测试的失败修正后，FC/codegen 测试通过，其余包在首轮通过。文档、vet、product-check、格式、差异空白及语言/本地链接检查均通过；最终提交的 Linux race/Windows 证据记录在对应 PR。
- 未调用真实 FC API、创建资源或推断分页/waiter/重试策略。XML、二进制流及其他签名协议仍使 #92 保持开放。
- 首轮 Linux race 在生成产品的隔离编译阶段触发了整套测试的 20 分钟上限；当时该编译子进程运行了 52 秒，另有独立的 180 秒期限，未报告断言或 race 失败。CI 整套测试上限调整为 30 分钟，子进程期限及 SDK 请求默认值不变。合并前仍要求最终提交的 CI 通过。

## 请求断言修正

- CI 暴露了一个把多字段 JSON 对象按固定字节顺序比较的测试。对象键顺序并不属于该操作的线路协议。
- 改为解码正文并比较准确字段和值，继续验证缺失与显式 false、空字符串的区别。调用前后所有权快照单独使用确定性 JSON。
- 本修正只改变测试断言，不改变 SDK 编码或签名。发布门禁也检查 Go 测试及独立对比模块，因此须在集成后的候选版本上更新消费者证据。
